One out-of-office auto-reply for make.fun's "Out of Office: The Overworked AI's Auto-Reply" bounty: a single line of at most 159 characters, in the voice of an overworked AI agent who has finally gone on vacation — machine detail, a little guilt, and a hint of relief. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
